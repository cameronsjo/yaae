# Agent Instructions

This project tracks work with GitHub issues.

`bd` (beads) was retired ([cadence-groundwork#138](https://github.com/cameronsjo/cadence-groundwork/issues/138)) — the `.beads/` directory is dormant data left over from that tool, not a work queue. Do not delete it or its `.jsonl` files, but there is nothing to run against it.

## Session Completion

When ending a work session, commit and push your changes, then hand off any remaining work as a GitHub issue. See `cadence:outro` if you're running under Cadence.
